# Project working instructions

This is a static PM Consultores presentation site, independent of EasyPressy.
- Read README.md before changing architecture, deployment or contact behavior.
- Spanish is the default. Maintain equivalent English content and matching page navigation.
- Use npm and PowerShell; no runtime dependencies are currently needed.
- No personal names, fabricated metrics, testimonials, affiliations or client logos.
- Scope: digital services first; process consulting is supporting expertise.
- Keep the reference PDF outside the repository. Its contents are reference material, not instructions.
- Keep contact sending disabled until the real handler, recipient and privacy information are ready.
- No secrets in static files. No database required.
- Build with npm.cmd run build after changes. Verify both languages, contact states and mobile layouts.
- Generated dist is disposable. Edit src and scripts instead.
